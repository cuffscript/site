읽는 그대로 이해되는
프로그래밍 언어, CuffScript

set, change, do: 같은 자연어에 가까운 키워드와, [num]·[word]처럼 이름이 있는 정규식 토큰으로 처음 배우는 사람도 코드를 읽을 수 있게 설계된 인터프리터 언어입니다. 설치 없이 이 페이지에서 바로 실행해 보세요.

IDE에서 실행해보기 언어 가이드 보기 
set returnable function fib(n) do:
    if n <= 1 do: return n end
    return fib(n - 1) + fib(n - 2)
end

set str email to "hi@cuffscript.dev"
if email is "[word]+@[word]+\.[word]+" do:
    print(f"{email} 은 올바른 이메일입니다")
end

print(f"fib(10) = {fib(10)}")

자연어에 가까운 문법

set number x to 5처럼 말하듯 쓰는 선언과 add ... to ... 같은 컬렉션 조작으로, 처음 보는 코드도 뜻을 짐작할 수 있습니다.

읽을 수 있는 정규식

\d, \w 대신 [num], [word] 같은 이름 있는 토큰으로 패턴을 표현해, 정규식을 처음 배우는 사람도 부담이 적습니다.

안전한 기본값

1부터 시작하는 인덱스, or_else 에러 복구, 재귀 깊이 제한, 정규식 폭주 방지까지 — 흔한 실수를 언어 차원에서 막아줍니다.

설치 없이 바로 실행

엔진이 WebAssembly로 컴파일되어 있어, 서버 없이 브라우저 안에서 직접 코드를 실행합니다. 링크 하나로 코드를 공유할 수도 있습니다.
